Model Context Protocol (MCP) & Agent Plug-in Guide

Enterprise Extensibility

SignaVerify exposes both a FastAPI REST API and a Model Context Protocol (MCP) Server, allowing autonomous AI agents (Claude, ChatGPT, LangChain, AutoGen) or enterprise backends (Java, C#, Node.js) to verify signatures with 1 line of code.

1. Model Context Protocol (MCP) Configuration

Add to your claude_desktop_config.json or Gemini agent manifest:

{
  "mcpServers": {
    "signature_agent": {
      "command": "python",
      "args": ["d:/AI_Internship_ManulaFernando_LOLC_Tech_2025/02_Project_Notes/Signature-validator-matcher/agent/mcp_server.py"]
    }
  }
}

2. Python SDK (3-Line In-Process or HTTP Integration)

from agent.client_sdk import SignatureAgentClient

client = SignatureAgentClient(mode="direct")  # Zero-network overhead
result = client.verify_document_for_customer(
    document_image="cheque_image.jpg",
    customer_id="CUST_001",
    document_type="Cheque"
)
print(f"Match: {result['is_match']}, Verdict: {result['verdict']}, Similarity: {result['similarity_percentage']}%")

3. REST API Endpoint (/api/v1/verify-document)

curl -X POST "http://localhost:8000/api/v1/verify-document" \
  -H "Content-Type: application/json" \
  -d '{
    "document_image": "data:image/jpeg;base64,...",
    "customer_id": "CUST_001",
    "document_type": "Cheque"
  }'
